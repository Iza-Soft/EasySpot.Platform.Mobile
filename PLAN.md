# EasySpot 2.0 — План

**Branch:** `dev-easyspot-2.0.0` · старата версия 1.2.0 е в `dev-easyspot-1.2.0`
**Цялостен план и архитектура:** [docs/EasySpot-2.0-Plan.pdf](docs/EasySpot-2.0-Plan.pdf)
**Документ за всеки етап:** `docs/stages/`

**Принцип (12.10):** всичко системно (местоположение, адрес, напомняния, известия, сензори) се прави с наш код: Kotlin на Android, Swift на iPhone. Без платени услуги. Ползва се най-добрият двигател, който телефонът вече има (Google fused на телефони с Google, по-късно евентуално Huawei fused, Core Location на iPhone), със системния Android API като резервен път.
